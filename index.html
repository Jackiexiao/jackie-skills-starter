复制成功

Jackie 推荐 Skills

超小白指南：①点“复制” ②把命令发给你的 AI（或在终端粘贴）③回车执行。

npx skills add Jackiexiao/jackie-skills-starter --all
如果你知道终端：打开终端粘贴执行。
如果你不知道终端：直接把这条命令发给 AI，并说「请代我执行」。

Skill用途示例
不会开终端？也没关系
你可以把已复制的命令直接发给 AI，并说：请你代我执行这条命令。
例如：Claude Code / Codex / Trae / OpenClaw 都可以代执行。
后续维护
npx skills ls
npx skills remove <skill-name>
