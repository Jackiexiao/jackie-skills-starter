# 🚀 一行命令，装好 Jackie 推荐 Skills（懒人版）

不研究原理，不折腾配置。
你只需要：**按场景选分类 → 一键安装 → 直接用示例开干**。

---

## 30 秒快速开始

```bash
npx skills add Jackiexiao/jackie-skills-dev --all
npx skills add Jackiexiao/jackie-skills-marketing --all
npx skills add Jackiexiao/jackie-skills-creator --all
npx skills add Jackiexiao/jackie-skills-everyday --all
```

> 适用于几乎所有主流 AI 工具：**Claude Code / Codex / Trae / OpenClaw** 等。

安装后马上可用（示例）：
- `用 webapp-testing 帮我测试注册到支付流程，输出失败点。`
- `用 copywriting 重写首页首屏，目标是提升注册率。`
- `用 baoyu-cover-image 给这篇文章做一张封面图。`

---

## 安装后管理（必备）

查看已安装：
```bash
npx skills ls
```

删除某个 skill：
```bash
npx skills remove <skill-name>
```
