# Jackie Skills Starter

一行命令安装全部推荐 skills（懒人版）：

```bash
npx skills add Jackiexiao/jackie-skills-starter --all
```

> 复制即用，不需要改命令。

## 小白也能用（两种方式）

### 方式 A：你自己在终端执行
1. 打开终端（Terminal）
2. 粘贴上面的命令
3. 回车执行

### 方式 B：让 AI 代你执行（推荐）
把命令发给你的 AI，直接说：

`请代我执行这条命令，并告诉我是否安装成功。`

适用于 Claude Code / Codex / Trae / OpenClaw 等。

## 按领域安装

```bash
npx skills add Jackiexiao/jackie-skills-dev --all
npx skills add Jackiexiao/jackie-skills-marketing --all
npx skills add Jackiexiao/jackie-skills-creator --all
npx skills add Jackiexiao/jackie-skills-everyday --all
```

## 维护命令

```bash
npx skills ls
npx skills remove <skill-name>
```
